# Webprogrammierung

## Voraussetzungen
- Node.js (zur Entwicklung wurde v.24.14.0 verwendet, andere/neuere Versionen sollten aber auch funktionieren)
- npm (sollte standardmäßig bei node.js mitgeliefert werden)
- das Repository ist gecloned

## Installation & Start
Die folgenden Anweisungen setzen voraus, dass sich der User im Projektverzeichnis befindet,
und sind für Windows konzipiert. Unter anderen Betriebssystemen sind Abweichungen nicht ausgeschlossen.

### Backend
```cmd
cd backend
npm install
node .\server.js
```

Das Backend sollte nun unter `http://localhost:3000/` laufen.

### Frontend
```cmd
cd frontend
npm install
npm run start
```

Das Frontend sollte nun unter `http://localhost:4200/` laufen.
